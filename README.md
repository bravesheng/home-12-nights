# 在家生存 12 夜

停電了。屋子裡有東西。白天找燈泡，晚上待在光裡，撐過 12 個夜晚！

3D 第一人稱的恐怖生存遊戲，不需要網路。

## 在平板上玩（Android）

1. 用 Chrome 打開遊戲網址。
2. 按右上角「⋮」→「加到主畫面」（或「安裝應用程式」）。
3. 之後從主畫面的圖示打開，沒有網路也能玩。

## 第二世界：夢核花園

打贏第一世界的 12 夜，前門會打開，走進第二世界：用樹當牆、有天花板、地上開滿花的怪花園（背包裡的東西都會帶過去）。這裡可以跳，有 5 隻新怪物（向日葵眼、千眼菇、草叢人、大嘴觸角蟲、眼花女孩），血月變成「萬物甦醒」。設計見 [docs/world2-plan.md](docs/world2-plan.md)。

已經破關過的話，在主選單連點版本號 5 下就能解鎖。

## 第三世界：末班列車

打贏第二世界之後坐上一班開往遠方的列車，在車上睡著了；醒來時車上的人全都死了，只剩自己一個。一列 1920 年代鍍金年代的豪華特快車，華麗但老舊、積灰：深胡桃木壁板、黃銅、暗紅絨布、裝飾藝術的花紋、蓋著白布的乘客，窗外是會捲動的風景。玩法多了三件事（設計見 [docs/world3-plan.md](docs/world3-plan.md)）：

- **白天列車停在車站**：從三節車廂往南的門下車，到月台、候車室、站務室找物資和四級寶箱（櫃箱、鐵寶箱、銀寶箱要 1 把鑰匙、鉑寶箱要 2 把）。開寶箱是賭：可能是物資，也可能跳出怪物（等級越高東西越好、怪物越強）；跑出怪物的寶箱打倒牠再開一次還是拿得到。天黑前 20 秒汽笛響、天黑前 3 秒車站鎖門，要先回到車上。
- **晚上列車必須一直開**：把木柴（25 秒）、木炭（55 秒）丟進機車室的火爐（一次最多 4 份；絨布椅墊、舊報紙是救急燃料）。火熄了列車先減速、5 秒後停下來，車外的東西會拍打車身、每秒扣血，補燃料 4 秒後重新開動。第 4 夜起偶爾會有「煤水車被撬開」偷走一份燃料。
- **第 6 夜紅月、第 3、7、10、12 天寒寂之境**：整天下雪、零下 100 度，多了「體溫」：在車站每秒掉 2 點、列車上 0.8 點，歸零就死。機車室的火爐（+3）、新的傳說級燈泡**大白燈**（3 格內 +5，走到它面前它會抱住你 +10，而且被打只扣一半的血）和熱可可、熱牛奶、泡麵都能回體溫。

4 隻新怪物（寫實風，照紙本設計圖做）：第 1 夜**克蘿諾斯・蕈裂衣**（鬼將級，長矛刺中夜晚的時鐘會倒退 10 秒，怕光和火爐）、第 4 夜**熔岩暴君**（羅判級，跺腳震倒你、走過留下熔岩，聖水槍冷卻再用平底鍋敲）、第 7 夜**墮落戰神**（羅判級，只在走道裡走，躲進包廂關上門就安全，從背後打傷害 3 倍）、第 10 夜和最後一夜**檮杌・九瞳**（判官級，用手電筒把九顆眼睛一顆一顆照到閉上牠就瞎了）。第一世界的怪物（爬行女除外）和大嘴觸角蟲、眼花女孩也都會來。第三世界的包廂門可以對著門按 E 關上。

打贏第二世界會播「上車、睡著、醒來」的過場動畫走進第三世界；已經破關過的話，在主選單連點版本號 5 下會一起解鎖第二、第三世界。

## 怪物圖鑑

主選單和暫停選單的「怪物圖鑑」會用遊戲裡的 3D 模型即時展示每隻怪物，而且會做出牠們在遊戲裡的動作（火柴人揮手、鳥腳女跳、草叢人從草裡站起來撲人、千眼菇流眼淚、檮杌的眼睛一顆一顆閉上……）。裝置開不了第二個 WebGL 畫布時會改用 2D 縮圖。

**沒見過的怪物只會顯示問號**（三個世界都是），名字和說明照樣看得到；怪物在你 8 格內出現超過 1 秒或碰到你就算見過（寶箱跑出來的也算）。紀錄跟解鎖世界的紀錄放在一起，刪存檔不會清掉；舊玩家第一次打開新版會照存檔的進度自動標成見過。

## 操作

- 平板：左半邊拖曳移動、右半邊滑動轉頭，右下角按鈕 E 互動（對著燈：拿燈泡就裝上、沒拿就拿起；第三世界對著火爐丟燃料、對著包廂門關門）、Q 使用、🔦 手電筒、⤒ 跳（第二、三世界）。
- 手機（螢幕短邊 520px 以下）：操作跟平板一樣，介面會自動縮小：橫放時提示排在最上面中間、小地圖和暫停鍵在右上角；直放時物品列放在搖桿和按鈕上面。
- 電腦：點畫面鎖定滑鼠，WASD 移動、滑鼠轉頭、E 互動、Q 使用、F 手電筒、空白鍵跳（第二、三世界）。

## 測試用網址參數

- `?world=2&night=6`：直接開第二世界的第 6 夜（加 `&kit=1` 會帶齊武器和燈泡）。
- `?world=3&night=4`：直接開第三世界的第 4 夜（第 2 夜以後火爐會先放好 3 塊木炭；`&kit=1` 另外帶 6 塊木炭、4 根木柴、3 把鑰匙）。
- `&cold`：這一天強制是寒寂之境；`&fire=0`：火爐一開始是空的（測列車停下來）。
- `?cut=1`：直接播第一世界破關的開門動畫；`?cut=2`：第二到第三世界的過場動畫。

## 自動試玩測試

```
node tools/playtest.mjs
```

用無頭 Chromium 自動跑 15 個情境：第一世界開新遊戲、第二世界第 6 夜、第三世界第 1 天（下車到月台、開寶箱、丟燃料、天黑鎖門）、第三世界火爐是空的（列車停下來被攻擊、補燃料後重新開動）、寒寂之境（體溫、大白燈抱住你）、第一世界怪物模型（火柴人、眼球花、爬行女、鳥腳女）、第二世界怪物模型（草叢人、大嘴觸角蟲、眼花女孩、向日葵眼、千眼菇）、第三世界怪物模型（蕈裂衣、熔岩暴君、墮落戰神、檮杌和大白排排站；三種都手電筒開關各拍一張）、平板觸控、小平板版面、手機版面（橫放和直放）、怪物圖鑑（問號、3D 怪物、三個世界、舊存檔的見過紀錄）、破關動畫、第二到第三世界的過場動畫、離線。會檢查 JS 錯誤、檔案載入失敗、提示有沒有壓到大字或面板、手機上介面有沒有擋住畫面中央或互相重疊，以及走路、手電筒、跳、天黑這些基本動作，截圖存在 `playtest-out/`。全部通過時結束代碼是 0。只跑某幾個情境：`PT_ONLY=w3,w3cold node tools/playtest.mjs`。

需要 Node 18 以上和 Playwright（Claude Code 雲端 session 已內建；自己電腦上：`npm i -g playwright && npx playwright install chromium`）。沒有 GPU 時 3D 是用軟體算的，FPS 很低，所以只能抓錯誤，看不出平板上順不順。

## 發布

```
./stamp.sh
```

寫入發布時間（台灣時間）、更新快取版本號，平板連上網路才會下載新版。Mac 和 Linux 都能跑。
