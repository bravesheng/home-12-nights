# 在家生存 12 夜

停電了。屋子裡有東西。白天找燈泡，晚上待在光裡，撐過 12 個夜晚！

3D 第一人稱的恐怖生存遊戲，不需要網路。

## 在平板上玩（Android）

1. 用 Chrome 打開遊戲網址。
2. 按右上角「⋮」→「加到主畫面」（或「安裝應用程式」）。
3. 之後從主畫面的圖示打開，沒有網路也能玩。

## 操作

- 平板：左半邊拖曳移動、右半邊滑動轉頭，右下角按鈕 E 互動、Q 使用、🔦 手電筒、R 拿起。
- 電腦：點畫面鎖定滑鼠，WASD 移動、滑鼠轉頭、E 互動、Q 使用、F 手電筒。

## 使用的程式庫

- [Three.js](https://threejs.org/)（MIT 授權，見 `lib/three-LICENSE`）
