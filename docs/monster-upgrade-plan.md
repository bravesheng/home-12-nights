# 舊怪物照第五世界的做法重做

2026/11/08 開始。第一到第四世界的怪物原本大多用球、圓柱拼起來，貼圖是簡單的畫布圖案。現在照第五世界 7 隻新怪物的做法，一隻一隻重做，每做好一隻給設計師看過再做下一隻。

## 做法

做法跟第五世界一樣，程式在 `js/render3d.js` 的「舊怪物照第五世界的做法重做」那一段。

- **網格**：用雕的，不再用球拼。
  - 頭用 `sculptGeo`：單位球上的點經過 `pt` 函式變成五官。
  - 身體用 `loftGeo`：一圈一圈的斷面。
  - 手腳、手指用 `tubeGeo`。
  - 不會分開動的零件用 `mergeParts` 合成一個網格，少畫幾次。
- **貼圖**：逐點畫。雜訊用 `fbm3`，在單位球或圓柱上取樣，繞一圈沒有接縫。
  - 用 `m5Tex` 預先畫好，存成 `tex/m5-<key>.webp`。
  - 改了畫法要跑 `node tools/make-monster5-tex.mjs`，新檔名要加進 `sw.js` 的 `ASSETS`。
- **材質**：
  - 有明暗、被手電筒照到會反光：`ownPhong`、`ownLM` 加 `shade`。
  - 需要時用 `withDetail` 疊照片細節。
- **接上遊戲**：在自己那一段最後登記 `UPG.<kind> = { build(r, g), sync(e, r, t, p, dt), view }`。
  - `view` 是圖鑑的鏡頭，格式跟 `BOOK_VIEW` 一樣。
  - `buildEnemy`、`syncEnemy`、圖鑑會先用 `UPG` 的；舊的 `build*`、`NEW_BUILD`、`BOOK_VIEW` 不用動（舊的程式之後再清）。
  - `syncEnemy` 一樣會先做共用的部分：位置、面向玩家、`r.mats` 的透明度、`r.eyes` 的閃爍。
  - 花（眼球花、向日葵眼、千眼菇）不是怪物，模型在別的地方，要自己找地方接。
- **分開做**：每個世界的怪物寫在 render3d.js 自己那一塊「第 N 世界重做的怪物」裡面，`sw.js` 的 `ASSETS` 也有每個世界自己的一行註解，新檔名加在那一行下面。這樣幾個 session 同時做，合併時才不會打架。
- **不能改的**：
  - 怪物的大小、碰撞、行為（`game.js`、`world*.js`）。
  - 顏色、特徵：例如黑影一定是黑的、紅眼睛。
- **設計師的要求**：寫實風、不要可愛風。有設計圖的要「跟我畫的一樣，不要亂改」。

## 黑影（2026/11/08）

- **身體**：用很濃的黑煙凝成的人形，大約 1.85 公尺。
  - 駝著背、頭往前伸。
  - 長長的手臂垂到膝蓋，手指又細又長。
  - 腰以下散成一縷一縷的煙，飄在地上。
- **臉**：沒有五官，只有兩個很深的眼窩，裡面的紅色瞳孔發光，照得眼窩周圍紅紅的。
- **煙**：身上一直冒出黑煙，外面有一層慢慢轉的薄煙，所以邊緣看起來一直在飄。
- **動作**：追你的時候更往前傾，頭偶爾抽一下，手臂跟著晃。
- **在遊戲裡的樣子**：
  - 黑暗中只看得到黑色的輪廓和兩個紅點。
  - 被手電筒照到才看得到頭和身體的形狀。
- **效能**：主選單的背景就有一隻黑影，所以模型開遊戲時就蓋好了，晚上出來不會卡一下。

## 第四世界

程式在 render3d.js 的「第四世界重做的怪物」那一塊，這一塊自己用的小工具是 `w4u` 開頭（`w4uPatches` 把一塊一塊的網格合成一個，每一塊的邊是硬的）。

### 葵氏奶昔（2026/11/08）

- **紙盒**：50 公分高的屋頂形紙盒，屋脊有封口，斜插一根白吸管。
  - 紙板泛白、有一點粉紅，細細的紙纖維、淡淡的受潮痕跡，每一面中間微微鼓起來、有一點壓凹。
  - 上下各兩條紅條紋（顏色照設計圖，偏暗的紅），摺邊的油墨磨掉了。
- **眼睛**（設計師：「眼睛要畫出來」）：
  - 一顆凸出來的真眼球，大約佔紙盒寬度的六成：泛黃的眼白、細細的血絲、灰色的小虹膜、黑瞳孔，瞪得很大。
  - 紙板到了眼睛周圍變成紅腫的肉：上眼皮的摺痕、下眼皮的細紋和眼袋、外眼角的魚尾紋、內眼角的淚阜，血色往紙上暈開。
  - 眼皮是紙盒正面的網格貼著眼球雕出來的（`shkSnap`，照 `crSnapLid` 的做法，上下眼皮的厚度在眼角外面平滑地接起來）；正面以眼睛為中心一圈一圈排，每條放射線都有一個點剛好在眼皮的邊緣上，邊緣才不會鋸齒狀。
- **動作**（跟舊的一樣）：醒著瞪著你、一跳一跳、噴奶時往後仰；睡著時站著、稍微歪一邊，另外一片眼皮從上眼皮裡面蓋下來一半，偶爾眨眼。
- **效能**：一隻的三角形 1608 → 3344，網格 8 → 3。
- **貼圖**：`tex/m5-shkCarton.webp`（每一面排在同一張 1024×512 上）、`shkSclera`、`shkIris`、`shkLid`。

### 紅涎偽人（2026/11/08）

- **頭**：很大的蛋形頭（頭頂離地 2.13 公尺，跟舊的一樣高，頭上的血條才不會蓋到臉），`sculptGeo` 雕的。
  - 兩顆凸出來、布滿血絲的眼睛瞪得很大，虹膜很小；周圍一圈鼓起來的眼眶（`mimLidGeo`，外圈沉到臉底下），左眼那圈是紅的（設計師：「一隻眼眶一圈紅」）。
  - 臉頰凹陷、鼻子只剩兩個洞；嘴張得很大（方方圓圓的深洞），裡面上下兩排長短不一、歪歪的爛牙。
- **紅涎**：從頭頂一道一道流過臉（尾端一顆血珠，網格也跟著鼓起來一點），從下唇流過下巴、脖子到胸口；濕濕亮亮的（反光貼圖 `mimHeadS`、`mimBodyS`，只有涎液和嘴裡會反光）。下唇垂著三條會晃的涎液，不管頭怎麼轉都往下垂，尾端的血珠一直滴到地上。
- **皮膚**：灰白、乾裂成一塊一塊（3D 的細胞雜訊 `w4uCell` 加上彎彎曲曲的扭曲，裂縫有深有淺）。
- **身體**：皮包骨，一根一根的肋骨、突出的髖骨、凹進去的肚子、背上的脊椎，長長的細脖子；細長的手臂往兩邊張開、手指很長，長腿、細長的腳。拿掉了破衣服。
- **動作**（跟舊的一樣）：站著歪頭、手臂張開抽動；四腳著地衝過來；被手電筒照到往後退、甩頭；敲門。四腳著地時舊的手腳會交叉在一起，改成腳往後蹬、手往前撐。
- **效能**：一隻的三角形 2576 → 8694，網格 36 → 16（黑影是 12534）。
- **貼圖**：`tex/m5-mimHead`、`mimHeadS`、`mimBody`、`mimBodyS`、`mimLimb`、`mimIris`。

### SCP-3008-2（2026/11/08）

- **頭**：照設計圖頭很大（0.43 公尺高的長蛋形），骨白色、像骷髏一樣的臉：兩個又大又深的黑眼窩、鼻子只剩一個倒過來的心形黑洞、凸出來的顴骨、凹下去的臉頰，細細的毛細裂紋。
  - 寬寬的紅嘴唇（上唇中間凹下去、下唇厚），乾裂、一道一道直的裂紋；兩片嘴唇中間露出一排牙齒。
- **脖子**：沒有肉，一節一節的脊椎（椎體、往後的棘突、兩邊的橫突、椎間盤），合成一個網格。
- **衣服**：黃底粗紫直條紋的短袖制服（洗舊的棉布、皺褶、污漬、縫線、羅紋圓領）；條紋照世界座標排，直直地一路到肩膀，不會在領口擠成一束。胸前綠色的「3008」名牌。
- **手腳**：白色的手臂（照設計圖離身體一點點），手指微微彎著；藍色的長褲（斜紋棉布、洗舊、膝蓋和褲腳的皺褶）、白色的球鞋（灰色的鞋底）。
- **動作**（跟舊的一樣）：白天背對著站、你靠近時頭慢慢轉過來看你；晚上巡邏、追你、揮拳。
- **效能**：一隻的三角形 2262 → 8144，網格 28 → 13。店員晚上最多 6 隻，所以頭、脖子、鞋子的格子都減過。
- **貼圖**：`tex/m5-stfHead`、`stfShirt`、`stfSleeve`、`stfPants`、`stfBadge`。
