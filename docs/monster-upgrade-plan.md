# 舊怪物照第五世界的做法重做

2026/11/08 開始。第一到第四世界的怪物原本大多用球、圓柱拼起來，貼圖是簡單的畫布圖案。現在照第五世界 7 隻新怪物的做法，一隻一隻重做，每做好一隻給設計師看過再做下一隻。

## 做法

做法跟第五世界一樣，程式在 `js/render3d.js` 的「舊怪物照第五世界的做法重做」那一段。

- **網格**：用雕的，不再用球拼。
  - 頭用 `sculptGeo`：單位球上的點經過 `pt` 函式變成五官。
  - 身體用 `loftGeo`：一圈一圈的斷面。
  - 手腳、手指用 `tubeGeo`。
  - 不會分開動的零件用 `mergeParts` 合成一個網格，少畫幾次。
- **貼圖**：逐點畫。雜訊用 `fbm3`，在單位球或圓柱上取樣，繞一圈沒有接縫。
  - 用 `m5Tex` 預先畫好，存成 `tex/m5-<key>.webp`。
  - 改了畫法要跑 `node tools/make-monster5-tex.mjs`，新檔名要加進 `sw.js` 的 `ASSETS`。
- **材質**：
  - 有明暗、被手電筒照到會反光：`ownPhong`、`ownLM` 加 `shade`。
  - 需要時用 `withDetail` 疊照片細節。
- **接上遊戲**：在自己那一段最後登記 `UPG.<kind> = { build(r, g), sync(e, r, t, p, dt), view }`。
  - `view` 是圖鑑的鏡頭，格式跟 `BOOK_VIEW` 一樣。
  - `buildEnemy`、`syncEnemy`、圖鑑會先用 `UPG` 的；舊的 `build*`、`NEW_BUILD`、`BOOK_VIEW` 不用動（舊的程式之後再清）。
  - `syncEnemy` 一樣會先做共用的部分：位置、面向玩家、`r.mats` 的透明度、`r.eyes` 的閃爍。
  - 花（眼球花、向日葵眼、千眼菇）不是怪物，模型在別的地方，要自己找地方接。
- **分開做**：每個世界的怪物寫在 render3d.js 自己那一塊「第 N 世界重做的怪物」裡面，`sw.js` 的 `ASSETS` 也有每個世界自己的一行註解，新檔名加在那一行下面。這樣幾個 session 同時做，合併時才不會打架。
- **不能改的**：
  - 怪物的大小、碰撞、行為（`game.js`、`world*.js`）。
  - 顏色、特徵：例如黑影一定是黑的、紅眼睛。
- **設計師的要求**：寫實風、不要可愛風。有設計圖的要「跟我畫的一樣，不要亂改」。

## 黑影（2026/11/08）

- **身體**：用很濃的黑煙凝成的人形，大約 1.85 公尺。
  - 駝著背、頭往前伸。
  - 長長的手臂垂到膝蓋，手指又細又長。
  - 腰以下散成一縷一縷的煙，飄在地上。
- **臉**：沒有五官，只有兩個很深的眼窩，裡面的紅色瞳孔發光，照得眼窩周圍紅紅的。
- **煙**：身上一直冒出黑煙，外面有一層慢慢轉的薄煙，所以邊緣看起來一直在飄。
- **動作**：追你的時候更往前傾，頭偶爾抽一下，手臂跟著晃。
- **在遊戲裡的樣子**：
  - 黑暗中只看得到黑色的輪廓和兩個紅點。
  - 被手電筒照到才看得到頭和身體的形狀。
- **效能**：主選單的背景就有一隻黑影，所以模型開遊戲時就蓋好了，晚上出來不會卡一下。

## 克羅諾斯・蕈裂（2026/11/08）

照設計圖 IMG_7321 做，程式在 render3d.js「第三世界重做的怪物」那一塊（`krBuild`、`krSync`；第三世界共用的小工具 `w3m` 開頭）。

- **身體**：1.5 公尺、矮胖駝背的哥布林，大肚子、O 型腿，手腳粗粗的。
  - 灰綠色乾裂的屍皮（`krSkinAt`：一部分的地方裂得比較多，有偏黃和偏灰紫的屍斑、疙瘩），用 `bumpMap` 做出凹凸，被手電筒照到看得出裂紋。
  - 皮膚的貼圖一張代表 30 公分寬的一塊、繞一圈沒有接縫（`W3M_SKIN`），身體繞一圈排 4 張；手腳的管子用 `w3mTube`（貼圖座標換過來），紋路大小跟身體一樣。
- **臉**（`krHeadPt`、`KR_FACE`）：粗粗的眉骨往中間壓低（很兇）、深陷的眼窩裡一點黃光、又大又往下勾的鼻子、高顴骨、往前凸的下巴。
  - 嘴巴咧開（`KR_MOUTH`），露出一排爛牙（缺了兩顆）和下排兩根往上翹的獠牙。
  - 上眼皮往下壓，瞇著眼睛。尖耳朵往兩邊伸出去。
- **蘑菇**（`krCapPt`：傘、捲起來的傘緣、菌褶、往下長進頭頂的柄是同一個網格）：
  - 紫色的傘面有往外放射的細紋和藍白色的斑點。
  - 傘緣有四個地方裂開，裂縫一路往頂上走，透出紫光（`emissiveMap`，一明一暗）。
  - 底下是淡藍色的菌褶，孢子一直往下飄（7 個很小的光點）。
  - 肩膀和腰上長著 3 朵小蘑菇（同一個形狀、格子很粗，合成一個網格）。
- **衣服**：肩膀上披著綠色的破布（下擺破破爛爛、有破洞），下擺垂著一條一條的布條；腰上綁著繩子和咖啡色的破腰布。布條用頭髮的做法，走路時會晃。
- **長矛**：木頭的柄、綁著皮繩、黑色石頭的矛尖。平常照設計圖斜斜地拿（矛尖往右上）。
- **動作**（跟舊版一樣）：
  - 一跛一跛地走：上半身一高一低、往一邊歪，兩條腿前後擺。
  - 刺矛：先往後拉（矛尖一直對準前面），再往前刺出去。
  - 被手電筒照到時縮起來、用手擋臉，蘑菇的裂縫變亮、一閃一閃。
  - 頭慢慢歪來歪去，偶爾咯咯笑（抖一下）。
- **在遊戲裡的樣子**：黑暗中只看得到蘑菇裂縫的紫光和兩個黃點；被手電筒照到才看得清楚整隻。
- **效能**：13508 個三角形（舊的 2604；黑影 12534），29 個網格（舊的 35）。貼圖 7 張（`tex/m5-kr*.webp`）。第一次蓋模型 18 毫秒（Mac）。

## 熔岩暴君（2026/11/08）

照設計圖 IMG_7321 做（`tyBuild`、`tySync`）。

- **身體**：2.6 公尺的岩石巨人，站得像大猩猩：上半身整個往前駝（`TY_LEAN`，在屁股那裡轉）。
  - 肩膀又寬又厚、背上隆起，兩肩上各有一塊大石頭。
  - 長長的手臂垂到膝蓋，拳頭很大；短短的粗腿、扁扁的大腳掌。
- **岩石**：用舊版就有的 `m-rock`、`m-lava` 這組照片（兩張的裂縫在同一個位置），不用另外畫貼圖。
  - `w3mRockMat`：顏色是 `m-rock`、發的光是 `m-lava`，從模型自己的座標三向投影（手腳再細也不會拉長）。
  - `w3mRockify`：網格照 `m-lava` 的裂縫往內壓、岩塊往外凸（高低不一，還有大一點的起伏），所以凹下去的縫剛好是發光的地方，輪廓也是一塊一塊的。裂縫越深越亮（`aLava`）。
- **臉**（`tyHeadPt`、`TY_FACE`）：方方的一塊岩石。
  - V 字形的粗眉骨往中間壓，蓋住半個眼睛（很兇）。
  - 眼睛是兩個熔岩洞（橘色、中間黃色，會發光）。
  - 張開往下撇的嘴，裡面是熔岩，上下一排尖尖的碎石牙。
- **動作**（跟舊版一樣）：
  - 慢慢地走，很重；熔岩一明一暗，走路時縫隙一開一合。
  - 跺腳：右腳抬起來再踩下去，整隻往上一頓，兩隻手往前甩。
  - 被聖水冷卻時全身變黑、眼睛和嘴巴的熔岩都暗掉，身上的熱氣也不見。
- **在遊戲裡的樣子**：黑暗中看得到一整片發光的裂縫和兩個兇狠的眼睛；被手電筒照到才看得到黑色的岩塊。
- **效能**：12446 個三角形（舊的 2748），20 個網格（跟舊的一樣）。沒有新的貼圖。第一次蓋模型 17 毫秒（Mac）。

## 墮落戰神（2026/11/08）

照設計圖 IMG_7321 做（`wlBuild`、`wlSync`）。

- **身體**：2.4 公尺、又高又瘦的骷髏戰士。
  - 胸口的鐵甲破了一個大洞（`wlPaintPlate` 的透明洞，邊緣是撕開的鐵），露出肋骨（有幾根斷了）、脊椎和後面空空的黑色胸腔（設計圖上那個黑洞和梯子一樣的脊椎）。
  - 兩肩各兩層鐵護肩，骨頭手臂套著鐵護腕。
  - 腰上垂著咖啡色的破布、綁著皮帶；腿上一圈一圈斜著綁的髒布條（`wlPaintWrap`），腳踝垂著破布條。
- **斗篷**（`w3mSheet`：照斷面做的一片彎彎的布，前面敞開）：很大一件，從肩膀垂到地上、越往下越寬，有直的皺褶。
  - 泛黃的白麻布，皺褶的地方偏藍灰（設計圖的淡藍色），越往下越髒，沾著鏽和乾掉的血。
  - 下擺一條一條往上撕開，前面的邊也是破的，還有破洞。
  - 用頭髮的做法（`aHair`），走路時下擺會飄，衝過來時往後甩。
  - 領口兩顆暗紅色的扣子（設計圖上的紅點）。
- **頭**：
  - 骷髏的臉（`wlSkullPt`、`WL_FACE`）：往中間壓的眉骨、很深的眼窩（邊緣銳利的洞，裡面一點暗紅的光）、鼻子的洞、高顴骨、咧著嘴的兩排牙。舊骨頭的顏色、裂紋，凹下去的地方卡著髒污。
  - 鐵頭盔（前面露出臉），兩根很大的彎角往外再往上翹，角上一圈一圈的紋路。
- **大劍**：比人還長（1.9 公尺），寬寬的劍身有幾個缺口、劍格、纏著皮的劍柄。平常劍尖拖在前面的地上，走路時劍尖冒火花。
- **動作**（跟舊版一樣）：
  - 面向牠走的方向，不是一直看著你（從背後打傷害 3 倍）。
  - 走路很慢、很重。
  - 揮劍前把劍舉過頭 0.6 秒（看到就要退開），然後往前伸、從右往左水平橫掃一劍，再慢慢放下來。
- **在遊戲裡的樣子**：黑暗中只看得到白斗篷淡淡的輪廓、角和一點暗紅的眼睛；被手電筒照到才看得清楚肋骨和大劍。
- **效能**：13532 個三角形（舊的 2688），29 個網格（舊的 33）。貼圖 4 張（`tex/m5-wl*.webp`），腰上的破布跟蕈裂共用 `krStrip`。第一次蓋模型 12 毫秒（Mac）。
