# 第五世界「世界夾層」設計計劃書

照設計師第五次手稿 `docs/sketches/IMG_7436.jpeg`（2026/11/01）。手稿右上角寫著「第五世界　世界夾層」，右邊和下面是文字說明，其他是 7 隻新怪物。

## 手稿上的文字說明 → 做法

| 手稿 | 做法 |
| --- | --- |
| 場地草原，沒有天花板 | 80×80 格的草原（`data.js` 的 `W5MAP`），草地一直延伸到霧裡，天上是跟著鏡頭走的漸層天空和雲（`render3d.js` 的 `makeSky5`） |
| 有樹、花、池塘、草 | 172 棵樹（4 種：粉紅色的花樹、白白像雲的樹、深綠色的圓樹、白楊；西北邊和東北邊的森林比較密）、173 朵大花（5 種顏色，西南邊是花海）、5 個池塘和一條從北流到南的河（兩座木橋）、地上一叢一叢的草 |
| 要自己去砍樹拿到板子 | 看著樹按住 E 砍 3 下，樹倒了掉 2 片木頭板子和 2 根木柴，2 天後長回來（`world5.js` 的 `chop5`、`regrow5`） |

| 河裡池塘可以抓魚吃 | 站在水邊看著水按住 E 釣魚（`fish5`），工作台可以烤魚、做釣竿 |

## 7 隻新怪物（模型在 `render3d.js` 的「第五世界」那一段，行為在 `world5.js`）

| 怪物 | 等級 | 第幾夜登場 | 行為 |
| --- | --- | --- | --- |
| 白日夢 | 鬼將 | 1 | 像雲一樣的一大團肉，慢慢飄到你頭上，底下滴黏液：站在底下理智掉、被滴到扣血（屋頂底下滴不到）；手電筒比較有效 |
| 404視線 | 鬼王 | 2 | 你看著牠就像畫面卡住不動（理智掉，這時候打牠比較痛）；一轉頭就衝過來，還會「跳格」往前閃 |
| 夢境切片 | 鬼王 | 3 | 住在水邊的硨磲貝，慢慢爬過來，靠近 3 公尺就咯咯笑、把殼夾下來；手電筒照著殼會闔起來（很硬） |
| 綠溫室 | 判官 | 5 | 不會動，哼搖籃曲把 10 公尺內的你慢慢吸過去、理智掉；被吸到旁邊就包進豆莢裡；在家裡聽不到 |
| 搖籃囈語 | 判官 | 6 | 飛在空中（牆擋不住），在頭上繞圈，每 6 秒俯衝下來撞你；被牠的眼睛盯著理智掉；手電筒照牠就退開 |
| 複製人 | 羅剎 | 8 | 很大、很慢，牆一下就被壓壞，碰到扣很多血、被推開 |
| 記憶洩漏源 | 酆都 | 10、12 | 大魔王：在遠處不會動，每 5 秒放出發光的「記憶」追著你，用手電筒照散 |

晚上一直會有第一世界的黑影（越後面越多），黑球、血淚女、小丑也會來。

## 跟第四世界共用的東西

第五世界在程式裡也算第四世界（`isW4()` 在第四、五世界都是 true，第五世界另外用 `isW5()`）：背包 16 格、自己蓋房子（板子、門、屋頂、斜坡）、家和溫馨度、火爐（第五世界畫成營火）、早晨禮物、神秘店員、寒寂之境的體溫、酸雨、存檔（`w4` 裡多一個 `w5`：砍倒的樹、自己做的家具編號；自己做的家具在 `furn` 裡有 `dyn`）。

## 跟朋友一起玩

第四世界的同步（`world4.js` 最後一段）第五世界照樣用，第五世界多的在 `world5.js` 的 `net5Apply`：

| 事件 | 內容 |
| --- | --- |
| `chop5` | 砍了一下（大家看得到、可以一起砍同一棵） |
| `fell5` | 樹倒了：掉的 2 片板子和木柴照 `uid` 送過去，樹上的東西掉到地上（`uid` 不變） |
| `loose` | 掉在地上的板子（工作台做的板子手上放不下時） |
| `mk5` | 工作台做的家具（方塊、火爐、床、椅子）：之後搬、放照第四世界的 `lift`／`put` |
| `bath5` | 沐浴球冒泡；洗出來的東西用第四世界的 `drop` 一個一個送，硬幣直接給丟的人 |
| `fx5` | 釣魚的水花 |
| `bolt5` | 閃電：房主決定打在誰（房主或朋友）旁邊，每個人照自己的位置算有沒有被打到；劈倒的樹房主送 `fell5` |
| `motes5` | 記憶洩漏源的光點：算這隻怪物的人放出來，每個人那邊的光點追自己 |

每天早上的 `day4` 和剛加入時的 `b4full` 都多了砍倒的樹的清單（`applyCut5`）；樹上和花上的東西跟第四世界架上的東西一樣照房主的。怪物的同步照 netmon.js（綠溫室把人吸過去、白日夢滴黏液這種範圍效果，作用在算這隻怪物的人身上，netmon 會把怪物交給離牠最近的人算）。

## 還沒做的
